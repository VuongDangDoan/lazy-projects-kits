## 4. Rules That Bind Codex Too

- Human gates sit at phase boundaries (G1–G5). Inside a phase, agents chain automatically.
- `_source/<repo>/` is the write path for Build agents only, within ticket scope. Never auto-commit source repos.
- Never infer legacy behavior — read `_source/` or run the legacy-scan ritual.
- Output contracts in `.agents/contracts/` are law — a missing field means the output is not done.
- Every code change produces a Doc Sync Plan (`.agents/contracts/doc-sync.schema.md`).
