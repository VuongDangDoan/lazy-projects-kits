## 6. Artifact IDs — GLOBAL, generated by scripts/next-id.sh

IDs are workspace-global sequences, NOT per-project or per-module prefixed.
Always call `scripts/next-id.sh` — never count files manually.

- User Stories:    `US-NNN`       → `scripts/next-id.sh us`
- Tickets:         `TICKET-NNN`   → `scripts/next-id.sh ticket`
- E2E Test Cases:  `TC-E-NNN`     → `scripts/next-id.sh e2e`
- ADRs:            `NNN-title.md` → `scripts/next-id.sh adr`
- Feature IDs:     per-module prefix (e.g. `ORD-036`) → `scripts/next-id.sh feature <module>`
- Business Rules:  `{{SHORT_CODE}}` project uses per-module BR prefixes from `project.config.json` (e.g. `BR-ORD-01`)
